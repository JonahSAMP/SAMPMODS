How to install

Back it up

Copy your GTA San Andreas folder before changing anything, so you can always roll back.

Add a loader

Install an ASI loader and CLEO if the mod needs one. Most fixes are plug-and-play after that.

Drop it in

Extract the download into the game folder (or the scripts folder for CLEO mods) and overwrite when asked.

Play

Launch the game. If something looks wrong, remove the last file you added and try again.
